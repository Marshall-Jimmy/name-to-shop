# 名字成店 · Name → Shop

输入任意字符串（中文名 / 汉字 / 英文 / 数字 / emoji），立刻生成一栋**专属于这个名字**的、独一无二的、会飞的 3D 店铺。

- 同一名字永远长出同一栋店（cyrb128 + sfc32 确定性种子）
- 可环绕观看、点击进店内部探索、一键让整栋店飞起来
- 可截图（带稀有度角标）、导出 `.glb` 模型、URL 种子链接分享复现
- 纯前端 · 零后端 · 纯本地运行

## 快速开始

```bash
npm install
npm run dev
```

打开浏览器访问 Vite 输出的地址（默认 `http://localhost:5173`）。

## 玩法

| 操作 | 入口 |
|---|---|
| 造店 | 输入任意名字 → 点「开业」（或 Enter） |
| 随机灵感 | 「🎲 随机一家」「☀️ 今日挑战」 |
| 进店探索 | 底部操作坞「进店」或直接点击 3D 门 |
| 飞行 | 「起飞」（快捷键 F）— 整栋店盘旋，相机跟随 |
| 截图 | 「截图」— 下载带稀有度角标与种子水印的 PNG |
| 导出模型 | 「导出」— 下载 `.glb`，可导入 Blender / Three.js 编辑器 |
| 分享 | 「分享」— 复制 `?name=...` 链接，同一名字 = 同一栋店 |
| 图鉴 | 收集 20 业态 × 16 风格，稀有度 N/R/SR/SSR/UR |
| 彩蛋手册 | 162 个彩蛋：生物字 / 数字梗 / 网络热梗 / 英文梗 |

试试这些名字：`猫猫咖啡` `龙王拉面` `888` `404` `尊嘟假嘟` `泰裤辣` `摸鱼大师` `雪糕刺客` `skibidi` `遥遥领先`

URL 直接带名字打开：`?name=张三`。

## 技术要点

- **确定性生成**：`cyrb128` 哈希输入 → `sfc32` PRNG，全项目无 `Math.random()`（UI 随机名除外）
- **几何铁律**：封闭轮廓 `ExtrudeGeometry` 挤出 + 强制构件校验（底座/墙/屋顶/门/窗/招牌），校验失败自动回退安全小屋模板——**出来永远是一栋店**
- **298 个参数化组件生成器**：15+ 槽位（结构/门面/招牌/装饰/飞行件/室内/特效/地面），组合出百万级变化
- **2D 立面 + 3D 体量**：Canvas 2D 绘制店面正立面（含 `fillText` 系统中文字体招牌，emissive + Bloom 发光），贴到 3D 挤出体块
- **五层风格随机化**：业态（20）× 风格流派（16）× 配色 × 材质 × 环境光照（7 种天光 + 天气）
- **渲染**：Three.js r185 `WebGPURenderer`（自动 WebGL2 回退）+ TSL Bloom 后期
- **资产**：Kenney / Poly Haven 等 CC0 模型与贴图（见 `LICENSES.md`）
- **交互**：3D 打字机 + 屏幕 HUD 操作坞（玻璃拟态、移动端自适应、safe-area 适配）；Raycaster 拾取、触屏优化
- **自检页**：`/check.html` 批量种子验证——组件覆盖 / 强制构件 / 确定性复现 / 彩蛋命中 / 渲染报错，当前 36 样本全绿

## 项目结构

```
src/
  main.js          # 状态机：loading → typing → shop（进店/飞行）
  core/            # cyrb128+sfc32 种子 · DNA 掷取 · tween · Web Audio 音效
  gen/             # 建筑骨架 + 298 组件生成器（registry 注册制）
  data/            # 业态/风格/彩蛋/光照/材质 JSON（数据驱动）
  scene/           # WebGPU 引擎 · 程序化天空 · 光照 · 天气 · Bloom
  ui/              # HUD 操作坞 · 3D 打字机 · 稀有度卡片 · 加载场景
  assets/          # CC0 GLTF/PBR 加载管理
public/assets/     # 下载的 CC0 模型与贴图（LICENSES.md 记录来源）
check.html         # 批量种子自检台
```
